# For AI agents working in this repository

This repository is a setup and usage manual for OpenCode (four languages: `th/`, `en/`, `fil/`, `lo/`), plus the files and scripts the setup uses.

- **Asked to set up / install OpenCode "per this manual"?** Follow [`AGENT-SETUP.md`](AGENT-SETUP.md) step by step. It has the rules, the commands, and a check for every step. The files to copy are in [`config/`](config/README.md).
- **Asked how to use the setup day to day?** The answer is in `en/USER-MANUAL.md`, section "Start to finish" (same section in `th/`, `fil/`, `lo/`).
- **Editing the manual itself?** The four language folders mirror each other page by page — change all four. Content is generic: no user names, machine paths, hosts, or credentials; use placeholders like `<user>` and `{env:NAME}`. `config/AGENTS.md` is the *global OpenCode rules file shipped by this manual*, not instructions for this repository.
