Root cause of the missing graft calls: brainstorming's first step says "Explore project context — check files, docs, recent commits", and the model followed it over AGENTS.md — even though graft-deep had injected a "use graft first" hint. The new global AGENTS.md rule reconciles the two, like the existing grilling rule.

What was changed

  • open-design and playwright off by default ("enabled": false) — enable per project in its opencode.json.
  • compaction.prune: true — drops tool outputs older than the last 2 turns / newest 40k tokens, in ≥20k chunks.
  • Global AGENTS.md: 3 new rules — graft first even inside a skill · ranged re-reads after compaction · when to search and save memory.
  • OPENCODE_DISABLE_EXTERNAL_SKILLS=1 — keeps ~/.claude/skills and ~/.agents/skills out (86 → 25 skills).
  • context7 as a remote MCP with the key from {env:CONTEXT7_API_KEY}, never inline.
